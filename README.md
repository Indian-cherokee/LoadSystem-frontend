## Настройка подключения к бэкенду

### Для разработки (localhost)
Бэкенд автоматически проксируется через Vite на `http://localhost:8080`. Никаких дополнительных настроек не требуется.

### Для production на GitHub Pages

#### Вариант 1: Использование переменной окружения VITE_API_URL

1. Создайте файл `.env.production` в корне проекта:
```bash
VITE_API_URL=http://ваш-ip:8080
# или для HTTPS:
VITE_API_URL=https://ваш-домен.com
```

2. Пересоберите и задеплойте проект:
```bash
npm run build
npm run deploy
```

**Важно:** 
- Если бэкенд работает по HTTP, а GitHub Pages по HTTPS, браузер может блокировать запросы (mixed content). В этом случае используйте HTTPS для бэкенда или туннель типа ngrok.
- Для ngrok: `VITE_API_URL=https://your-ngrok-url.ngrok.io`

#### Вариант 2: Без настройки VITE_API_URL

Если `VITE_API_URL` не задана, приложение автоматически использует моковые данные. Это позволяет работать фронтенду на GitHub Pages без бэкенда.

### Проверка подключения

Откройте консоль браузера (F12):
- Если бэкенд доступен: увидите "Бэкенд доступен"
- Если бэкенд недоступен: увидите "Production на GitHub Pages без VITE_API_URL, используем моковые данные"
